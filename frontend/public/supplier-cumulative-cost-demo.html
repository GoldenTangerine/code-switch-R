Dashboard Module Demo

首页供应商花费点击后，弹出今日累计消费金额折线图

这个示例模拟了 dashboard 中的“供应商卡片”模块。用户点击供应商的花费金额后，会打开弹窗， 用 ECharts 展示当天 API token 消费金额随时间累计增长的趋势。

Chart Unit USD 这里统一按 USD 展示。你要换成人民币也简单，把 `currencyCode` 改成 `CNY` 就完事。
