# 发布 v2.9.01

- 变更时间：2026-07-17 12:42:18 CST（Asia/Shanghai）

- 版本号由 `v2.9.00` 推进到 `v2.9.01`。
- 新增 Claude 代理认证字段选择，代理接管期间只保留 `ANTHROPIC_AUTH_TOKEN` 或 `ANTHROPIC_API_KEY` 其中之一。

- 同步本机、CLI 高级编辑与 WSL 自动配置的代理认证字段，保持外部 `--settings` 文件不变。
- 更新 `RELEASE_NOTES.md`，供 GitHub Actions 按 `v2.9.01` 提取本次版本说明。
- 同步 macOS、Windows、Linux 构建元数据，并通过推送 `v2.9.01` Tag 触发全平台自动打包。
