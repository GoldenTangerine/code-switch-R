# Cursor/Codex 会话粘滞归一

- 变更时间：2026-08-19 22:17:10 CST
- 涉及范围：Codex 代理会话识别、请求日志、首页连接详情

## 变更内容

- 优先使用 `x-cursor-conversation-id` 或结构化请求体（含顶层字段）中的 Cursor 会话标识识别会话。
- 保留 Codex 显式线程/会话字段作为第二优先级，并覆盖仅提供父级或根级线程、会话、对话标识的请求。
- 仅提供父级标识时按根会话处理，避免节点与父节点形成自引用；请求头补充子节点时仍保留请求体中的父关系。
- 子节点只有显式根标识时以根节点作为粘滞继承回退，且请求头覆盖节点时保留请求体根关系。
- parent/root 字段不再使无关顶层 `id` 抢占显式会话标识。
- 对包含 `input` 的 Codex Responses 请求，在无显式会话标识时使用 `prompt_cache_key` 归一会话。
- 会话来源统一从入口原始请求体识别，不受供应商请求体覆盖或协议转换影响。
- 请求日志新增 `session_identity_source` 字段，旧数据库自动迁移；不保存原始会话 ID 或缓存键。
- 首页供应商连接详情的活跃和历史记录显示识别来源标签，并为亮色、暗色主题提供一致的视觉区分。
