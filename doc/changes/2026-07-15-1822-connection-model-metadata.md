# 连接详情模型参数展示

- 变更时间：2026-07-15 18:22:40 CST（Asia/Shanghai）
- 涉及范围：首页连接详情、供应商并发状态、请求参数快照、中英文文案

## 变更内容

- 活跃连接新增思考强度与最大输出参数快照，分别记录请求值、最终值及最终来源。
- Claude 模型路由开启时，请求模型和实际模型分别显示对应参数；其他平台保持单模型布局并显示最终参数。
- 最大输出兼容 `max_tokens`、`max_output_tokens`、`max_completion_tokens` 与 Gemini 对应字段，协议转换保持原请求来源。
- 修复请求体同时存在多个最大输出别名时误选字段的问题：请求值按入口协议解析，实际值和兼容重试按最终上游协议解析。
- 模型映射、请求体覆盖和原请求使用独立来源标识；兼容重试移除思考参数时同步刷新活跃连接状态。
- 模型旁固定显示“思考”和“输出”标签，空值显示 `-`，最大输出按 1024 进制缩写；完整值与来源通过鼠标悬停或键盘聚焦查看。
- 历史连接不新增数据库字段：实际模型复用已有最终思考强度，其余未持久化参数显示 `-`。
- 参数标签支持亮色、暗色和窄窗口布局，长自定义值使用省略显示并在详情中保留完整内容。
- 活跃/历史、单模型/双模型改为统一的展示项与模型行生成逻辑，减少重复参数解析和模板分支。

## 问题复盘

- 根因类型：隐式假设与测试覆盖缺口。旧逻辑假设请求体只有一个最大输出别名，固定顺序无法表达最终上游协议。
- 结构预防：`providerRequestPlan` 显式保存参数协议，构建和兼容重试共用协议感知解析。
- 测试预防：新增多别名冲突、各协议字段、兼容重试刷新、单模型和双模型展示行回归测试。
