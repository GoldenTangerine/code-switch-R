# 发布 v2.9.12

- 变更时间：2026-07-23 11:52:59 CST（Asia/Shanghai）
- 涉及范围：应用版本、供应商成功率、请求日志、统计展示、Wails 构建元数据、发布说明、Git Tag、GitHub 自动打包

## 变更内容

- 应用版本从 `v2.9.11` 更新为 `v2.9.12`。
- 收到 `response.completed` 或成功的 `response.done` 后保持供应商成功，客户端后续关闭不再覆盖为 `499/502` 失败。
- 完成前的客户端取消、本地并发限制和代理内部错误从供应商成功率分母排除。
- 请求日志新增成功、失败、排除三态结果和原因，成功率统一按 `success / (success + failure)` 计算。
- 未知结果值统一规范化并回退 HTTP 状态，保证汇总、失败列表、可用性和聚合统计一致。
- 日志页展示已排除请求数，首页成功率提示展示成功、失败和排除数量。
- 同步 macOS、Windows、Linux 平台构建元数据。
- 创建并推送 `v2.9.12` Tag，触发 GitHub Actions 全平台自动打包。
