# 托盘供应商状态指标

- 变更时间：2026-08-04 10:13:05 CST（Asia/Shanghai）
- 涉及范围：macOS 托盘弹窗、供应商今日统计、近期性能指标、中英文文案

## 变更内容

- 在供应商额度模式的供应商名称下方新增成功率、请求数、Tokens、花费、首字延迟和生成速度。
- 成功率、请求数、Tokens 和花费使用今日供应商统计；首字延迟和生成速度沿用跨天最近 5 条成功流式请求口径。
- 供应商统计优先按供应商 ID 匹配，仅对缺少 ID 的旧统计按名称回退，避免同名供应商串数据。
- 成功率沿用首页健康阈值分色，无数据时保持固定布局并显示零值或占位符。
- 指标查询仅在托盘打开并获得焦点时运行；隐藏或失焦后立即销毁定时器和待执行刷新，重新打开时立即刷新。
- 同一供应商的指标查询短暂失败时保留上一次有效数据；切换供应商时立即显示占位，避免串数据。
- 新增四列核心指标与两列性能状态布局，并同步亮色、暗色主题样式和中英文文案。
- 加深亮色主题的成功率、花费和速度颜色，使小字号文本对比度高于 `4.5:1`。
- 首页与托盘共用 Tokens、成功率和生成速度格式化函数，避免口径偏移。
- 发布版本推进到 `v2.9.20`，同步更新说明、应用版本常量与全平台 Wails 构建元数据。
- 移除托盘内容容器的内部滚动条，窗口高度改为按实际内容动态撑开。
- 原生窗口最大高度按当前屏幕工作区动态限制，并在多屏切换或重新打开托盘时重新定位；屏幕信息不可用时使用安全回退值。
- 托盘失焦期间不提交在途刷新产生的窗口尺寸更新，减少隐藏状态下的无效调用。
- 超过屏幕可用高度时保留触控板/滚轮滚动能力并隐藏滚动条，避免超长供应商额度内容被裁剪。
- 托盘显示前先按当前屏幕收紧旧窗口高度，激活后立即测量初始内容，避免跨屏或首次打开时等待网络请求导致内容暂时不可见。
