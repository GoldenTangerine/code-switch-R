# CodeNotch 联动评审修复

变更时间：2026-09-08 17:48:00（Asia/Shanghai）。

## 涉及范围

Code Switch R 托盘刷新生命周期、共享快照服务、额度请求服务；CodeNotch 额度展示和图标资源。

## 变更内容

- 相同预算刷新周期不重复重启定时器，修复 500ms 活动轮询导致预算永不刷新的问题。
- 保留禁用供应商元数据，ID 严格匹配；禁止同名歧义回退及旧统计串用。
- HTTP 请求和响应读取支持取消，脚本支持取消及 30 秒执行上限；退出继续等待工作线程结束，避免关闭数据库后访问。
- 重建丢失的缓存目录，初始发布失败保留重试路径，错误日志独立节流。
- 复用普通配置版本、缩小 Gemini 复制范围、仅对额度查询输入计算指纹；同平台统计共享缓存，前端跳过相同内容的供应商重建。
- CodeNotch 明确显示未开始周期，排除无效圆环读数；复用 723 个 Lobe 图标离线资源（PNG 合计约 1.7 MB），包含许可证。

## 验证结果

- 托盘单元测试 43 项通过，包含 180 秒内持续轮询仍触发 3 次预算刷新。
- Vue/TypeScript 类型检查通过。
- Go 额度及联动定向测试和 race 检查通过，覆盖同名身份、配置缓存失效、目录重建、慢 HTTP 取消、响应体取消、脚本中断及额度统计口径。
- CodeNotch 全 Sources 类型检查通过；存在项目原有 Swift 6 兼容警告。
- 原生独立验收验证资源读取、快照更新、失联恢复、关闭联动、排序和悬停布局。完整 XCTest 受缺少 Xcode 限制。
- 未构建或启动 Code Switch R，未提交或替换已安装应用。
