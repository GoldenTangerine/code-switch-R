# 供应商并发标签活跃态强化

- 变更时间：2026-08-03 12:57:30 CST（Asia/Shanghai）
- 涉及范围：首页供应商卡片、供应商编辑表单、并发状态接口、代理限流与中英文文案

## 变更内容

- 首页并发标签在有活跃连接时使用青色辉光呼吸效果，达到有效上限后切换为琥珀色满载状态。
- 空闲标签降低背景和边框对比度，悬停与状态切换不会改变标签尺寸；减少动态效果模式下保留静态状态样式。
- 并发上限留空继续表示无限制，显式设置为 `0` 表示满载，`1 - 999` 表示对应并发上限。
- 平台并发限制开关关闭时仅展示实时状态，不执行上限；开启后上限 `0` 会拒绝新连接并尝试下一供应商。
- 运行中将上限改为 `0` 时不终止已有连接，仅阻止后续连接。
- 兼容未配置并发上限的历史供应商配置，并补充前后端回归测试。
- 复制 Claude、Codex、自定义或 Gemini 供应商时保留并发上限，避免 `0` 被转换为无限制。
- 同步 Wails 的 Provider 与 GeminiProvider 并发上限绑定类型，并移除前端临时类型补丁。
