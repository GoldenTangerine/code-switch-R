# 模型映射独立开关

## 变更时间

2026-07-16 09:37:51 CST（Asia/Shanghai）

## 涉及范围

- 首页供应商编辑
- Claude、Codex 与自定义 CLI 模型映射
- 模型匹配、路由、校验与配置持久化

## 变更内容

- 每条模型映射增加独立开关，并显示“启用数 / 总数”。
- 已保存规则切换后立即持久化，仅更新开关状态；保存失败时自动回滚。
- 新增或重命名的草稿规则随供应商表单保存，新规则默认开启。
- 关闭的规则仍可编辑和删除，但不参与精确匹配、通配符匹配、Claude 路由、模型聚合与配置校验。
- 关闭高优先级规则后继续匹配其他开启规则；全部关闭时沿用全局未命中策略。
- 保存时清理无效或非关闭状态，历史配置缺失开关字段时默认全部开启。
- 修复 Claude 路由提前过滤供应商，导致全部规则关闭后无法执行透传策略的问题。
- 开关即时保存期间锁定弹窗关闭与提交操作，过期请求不再回滚其他供应商的表单状态。
- 增加开关并发锁、失败回滚、过期请求隔离、草稿规则和 Claude 动态透传回归测试。
