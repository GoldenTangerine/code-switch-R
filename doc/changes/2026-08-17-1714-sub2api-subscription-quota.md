# Sub2API 订阅额度查询

## 变更信息

- 变更名称：Sub2API 订阅额度查询
- 变更时间：2026-08-17 17:14:14 CST（Asia/Shanghai）
- 涉及范围：供应商额度查询配置、首页供应商卡片、托盘弹窗、额度脚本预设

## 变更内容

- 在 NewApi 后新增 Sub2API 订阅查询模版，支持独立配置 Base URL 和 API Key，留空时沿用供应商配置。
- 默认请求 `GET {{baseUrl}}/v1/usage`，通过 Bearer API Key 鉴权。
- 按接口响应展示日、周、月订阅额度，额度限制为 0 时隐藏对应周期。
- 日额度按次日 00:00 刷新，周额度按窗口开始时间加 7 天刷新，月额度按订阅到期时间刷新。
- 三个周期均无限制时，首页供应商卡片显示“不限额”，托盘弹窗显示 `∞`，且不会触发额度耗尽自动停用。
- 无限状态仅依据 Sub2API `subscription` 中三个完整且明确为 0 的 limit 字段；其他查询模版的零余额仍表示耗尽。
- 部分 Sub2API 周期 limit 为 0 时隐藏该周期；limit 字段缺失、非法或存在非零值时不判定为全无限订阅。
- Sub2API 脚本误报不限额但原始 limit 未满足条件时，保留脚本提取的真实余额，避免错误触发额度耗尽。
- 倒计时归零后强制刷新远程货币额度，并保留现有缓存和失败回退行为。
- Sub2API 查询脚本支持编辑、保存及设置全局默认预设。
- 切换查询模版时自动加载目标模版脚本，避免沿用上一模版的请求地址。
- 首页和托盘统一使用日、周、月周期标题；周窗口为空时不生成错误倒计时。
- 首页和托盘进度条补充辅助技术可读的进度语义，长套餐名称在窄宽度下省略并保留完整悬浮提示。
- 补充默认脚本执行、无限订阅、自动停用、周期标题及托盘展示的回归测试。
