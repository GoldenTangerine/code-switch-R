# 托盘实时调用供应商展示

- 变更时间：2026-08-18 15:10:00 CST（Asia/Shanghai）
- 涉及范围：托盘弹窗、实时供应商并发状态、首页供应商 Tab 过滤、中英文文案、并发状态批量查询服务

## 变更内容

- 托盘按供应商实时并发状态展示所有正在调用的供应商，不再固定显示路由中的第一个供应商。
- 同一平台的多个供应商分别展示调用状态、活跃请求数、额度和今日统计；区块按路由配置顺序保持稳定。
- 没有活跃请求时保留该平台最近调用的供应商。
- 托盘平台按照 `home_provider_tabs` 过滤；开启“其他”时加载全部 Custom CLI 工具。
- 实时状态仅覆盖 Claude、Codex、Gemini、Grok Build 和 Custom CLI 等当前可由代理并发状态识别的平台。
- 托盘获得焦点期间每秒刷新轻量调用状态；失焦、隐藏或卸载时清除状态定时器，避免后台资源占用。
- 多供应商区块中的 5 小时额度倒计时继续使用秒级更新，并随托盘刷新生命周期统一启停。
- 首次打开时先加载可见平台和实时活动状态，再渲染供应商详情，避免短暂显示错误的首个供应商。
- 实时并发状态与最近调用状态独立容错；最近调用查询失败时仍更新正在调用的供应商。
- 新增并发状态批量查询，将每秒 Wails 状态调用从随平台数量增长收敛为固定两次。
- 清理不可达的旧单供应商展示链路，并为多供应商溢出场景增加轻量滚动条。
- 平台开关变化或托盘关闭时使旧活动刷新任务失效，避免旧快照写入新平台并减少关闭后的额度查询。
- 新增供应商调用状态归并单测，并同步中英文托盘文案。
