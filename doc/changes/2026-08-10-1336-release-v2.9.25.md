# 发布 v2.9.25 与 v2.9.26

- 变更时间：2026-08-10 13:36:55 CST（Asia/Shanghai）
- 涉及范围：macOS 27 托盘、Wails 运行时补丁、Darwin 构建任务、GitHub Actions、Linux GTK3 兼容、版本元数据与发布说明

## 变更内容

- 修正此前将 Wails beta.6 误判为已包含 macOS 27 托盘修复的问题；保持 beta.6 版本不变，仅移植官方 PR `#5760` 的托盘输入补丁。
- macOS 27 改用 `NSGestureRecognizer` 处理状态栏输入，并使用 `performClick:` 打开原生菜单；macOS 26 及以下保持原有事件路径。
- 托盘弹窗显示后增加 `300ms` 首次失焦保护，避免状态栏点击事件尚未结束时立即隐藏。
- Darwin 构建通过临时 patched module 和 `modfile` 应用补丁，不提交完整 Wails vendor，不影响 Windows 与 Linux 依赖解析。
- GitHub Release 工作流增加 macOS 补丁接入校验；Linux 继续使用 GTK3/WebKit2GTK 4.1 独立构建和打包配置。
- 应用版本推进至 `v2.9.25`，同步全平台构建元数据和发布说明，通过 `v2.9.25` Tag 触发 GitHub 自动打包。

## 验证结果

- Wails beta.6 补丁准备任务：通过，补丁可重复应用且临时 `modfile` 正确解析到 patched module。
- patched Wails `pkg/application` macOS Objective-C/Go 编译：通过。
- 应用根包 macOS 编译：通过。
- `TestTrayWindowFocusGuardSuppressesOpeningBlurOnly`：通过。
- Darwin 构建 dry-run：通过，最终 `go build` 使用临时 `modfile`。
- Linux GTK3 生产构建 dry-run：通过，继续使用 `production,gtk3` 标签。
- GitHub Release workflow YAML 解析与补丁静态校验：通过。
- `git diff --check`：通过。
- 按项目限制未启动应用或执行完整打包；实际产物由 GitHub Actions 构建。

## 后续修正 v2.9.26

- `v2.9.25` 自动打包本身成功，但 Wails beta.6 实际输出 `CodeSwitch.deb` 和 `CodeSwitch.rpm`，原工作流使用旧的 `codeswitch_*.deb` / `codeswitch-*.rpm` 匹配规则，导致两个安装包未进入 Release。
- Linux Job 改为校验并上传精确文件名，生成对应 SHA256；Release 阶段不再静默忽略缺失的 DEB/RPM。
- 中英文安装命令同步为 `CodeSwitch.deb` 与 `CodeSwitch.rpm`，版本推进至 `v2.9.26` 后重新触发全平台自动打包。
- Wails beta.6 `tool package` 输出命名源码核验：通过，输出规则为 `<ExecutableName>.<format>`。
- GitHub workflow YAML、`v2.9.26` 发布说明提取、版本元数据一致性与旧文件名清理：通过。
- 根包测试与 `git diff --check`：通过；链接阶段仅有本机 macOS SDK 版本警告。
