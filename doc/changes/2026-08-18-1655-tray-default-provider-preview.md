# 托盘默认供应商预览

- 变更时间：2026-08-18 16:55:00 CST（Asia/Shanghai）
- 涉及范围：托盘弹窗、供应商路由预览、并发状态批量查询、中英文文案、单元测试

## 变更内容

- 有活跃请求时继续展示全部正在调用的供应商；无活跃请求时展示下一次新会话预计调用的供应商，并标记为“默认”。
- 默认候选按启用状态、连接配置、Level、用户顺序、黑名单、轮询游标、会话容量与负载、并发限制进行只读预览。
- 轮询预览不推进游标；请求模型未知时不执行模型兼容性过滤，实际请求仍以运行时模型路由结果为准。
- 无可路由供应商时显示“暂无可用供应商”；运行态接口失败时显示“查询失败”，避免混淆配置状态。
- 批量接口异常遗漏单个平台时，同样按“查询失败”处理，不误报为没有可用供应商。
- 默认供应商复用现有名称、图标、今日统计和已配置额度展示；无候选时跳过供应商日统计查询。
- 托盘只查询首页供应商设置中已显示且支持代理运行态的平台；失焦、隐藏和卸载时继续清除相关刷新定时器。
- 批量运行态接口一次返回并发计数与默认候选，移除托盘对请求明细、最近调用状态和额度回退候选的依赖。
- 没有已建立会话负载时，默认候选按无会话路由预览轮询；存在会话负载时再应用会话容量排序。
