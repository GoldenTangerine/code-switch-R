# 发布 v2.9.02

- 变更时间：2026-07-17 15:39:39 CST（Asia/Shanghai）
- 涉及范围：日志用量统计、计价模型筛选、自动刷新、应用设置、应用版本、Wails 平台构建元数据、GitHub Release 更新说明

## 变更内容

- 版本号由 `v2.9.01` 推进到 `v2.9.02`。
- 日志页新增请求明细、Provider 统计和模型统计三个数据视图，支持指标排序和数据视图记忆。
- 新增全局计价模型筛选，并统一数据库筛选、统计分组与请求主展示口径。
- 请求明细补充计价模型和路由模型双层展示，Provider 统计补充平均耗时，模型统计补充六位小数单次均价。
- 自动刷新支持关闭、5、10、30、60 秒档位并持久化，修复刷新重叠和统计加载状态提前结束。
- Provider 变化后即时级联模型选项，Provider 统计按 Tab 激活状态加载，降低无用聚合扫描。
- 更新 `RELEASE_NOTES.md`，供 GitHub Actions 按 `v2.9.02` 提取本次版本说明。
- 同步 macOS、Windows、Linux 构建元数据，并通过推送 `v2.9.02` Tag 触发全平台自动打包。
