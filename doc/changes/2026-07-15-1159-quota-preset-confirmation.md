# 额度预设应用内确认弹窗

- 变更时间：2026-07-15 11:59:56 CST（Asia/Shanghai）
- 涉及范围：首页供应商编辑、额度查询配置、预设删除、未保存修改确认、中英文文案

## 变更内容

- 移除额度预设编辑器对浏览器原生 `confirm` 的依赖，避免桌面 WebView 不显示确认框时操作无响应。
- 删除预设改用应用内确认弹窗，确认后按捕获的预设 ID 执行持久化删除。
- 删除过程中禁用确认弹窗关闭和重复提交；失败时回到编辑器显示错误。
- 关闭、新增和切换预设时，未保存修改统一通过应用内弹窗确认是否放弃。
- 保持现有删除规则：默认预设删除后自动选择下一项，最后一个预设删除后移除整个预设组。
- 补充中英文删除、放弃确认标题和按钮文案。
