# CPT 云端价格与条件计费

- 变更时间：2026-09-07 11:31:51，Asia/Shanghai（UTC+08:00）。
- 涉及范围：云端价格同步与持久化、定价资源、供应商价格解析、请求转发与日志统计、价格及日志界面。

## 变更内容

- 云端地址改为 `https://cch-plus.com/pricing/v1/models.json`，按 CPT v1 JSON 校验结构、币种和价格，转换每百万 token 单价；默认选择有效官方报价，兼容模型别名及同名择优。
- 下载超时调整为 30 秒，上限为 64 MiB，超限明确报错；保留最终地址检查。旧 TOML 解析辅助函数保留，远程同步仅使用 JSON。
- 保存完整有序轨道，按首个所有条件满足的规则计费，支持上下文阈值及包含边界、服务档位、请求头和操作标识。字段倍率优先于整体倍率，云端规则不重复叠加旧长上下文规则。
- 同步冲突展示双方轨道；保留维持整套原有规则，覆盖整体采用云端规则。手动编辑价格清除云端轨道，Claude 官方同步来源维持既有优先级。
- 供应商报价区分字段缺失与明确零价，修正 OneHub 独立输入、输出价格转换。仅返回模型名时回退项目报价，部分报价按字段补齐；云端倍率只影响云端来源字段。
- 从实际上游请求及响应采集必要计费条件，不依赖正文保存；重试重置旧条件。新增 `request_log.pricing_snapshot`，保存实际单价、逐字段来源、命中轨道及完整性。
- 日志读取已有快照时不重算；统计回填保留有快照或已有定价标记的原始费用，包括零费用。历史缺少条件信息时不推断条件轨道。
- 模型列表和冲突弹窗增加只读规则摘要，日志展示实际快照与混合来源，供应商列表正确显示缺失价格和明确零价；补充中英文文案。

## 评审修正

修正时间：2026-09-07 11:50:07，Asia/Shanghai（UTC+08:00）。

- Claude 官方同步主动清除旧云端轨道，兼容修复已有官方来源中残留的云规则，保证展示单价与实际计费一致。
- 按实际上游协议记录输出是否包含思考 token。Gemini 缺少独立思考价格时采用对应输出档位单价；OpenAI 将已包含的思考量从普通输出部分扣除，避免重复计费。补齐 Gemini 仅返回总量时的输出估算口径。
- CPT 导入上下文长度、最大输出长度和能力字段；缺失元信息保留原值，明确 false 可以覆盖旧能力。元信息随价格持久化，且仅元信息变化也触发更新。
- 集中维护 token 计费字段映射与前端支持字段集合；规则摘要过滤不支持的计费维度，日志按相同支持字段展示，避免暴露缺失翻译键。
- 轨道正则在加载或规则复制时预编译，并复用不可变编译结果；规则等价比较排除编译缓存，避免误判更新。无效正则保持不匹配。
- 新增官方来源切换、元信息合并及序列化、流式及非流式 Gemini/OpenAI 思考计费、供应商混合报价、正则缓存和不支持字段展示回归。
