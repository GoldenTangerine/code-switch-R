# 发布 v2.11.1

- 变更时间：2026-08-18 13:33:17 +0800（Asia/Shanghai）
- 发布版本：`v2.11.1`
- 涉及范围：首页供应商卡片、供应商余额查询缓存、错误悬浮交互、前端国际化、发布元数据

## 变更内容

- 余额查询失败时清除历史余额缓存，卡片第一层仅显示错误图标和刷新按钮。
- 将完整失败详情收纳到错误图标悬浮窗，支持延迟打开、点击锁定、触控点击、Esc/外部关闭和双击复制。
- 卡片布局或统计状态变化后自动重新计算 Teleport 悬浮窗位置。
- 补充错误悬浮交互、复制 payload 及失败后恢复成功的回归覆盖。
- 更新应用版本常量、构建配置和全平台版本元数据。
