# 首字耗时单位进阶显示

- 变更名称：首字耗时单位进阶显示
- 变更时间：2026-07-13 20:58:43 CST
- 涉及范围：日志性能列、首页供应商卡片、前端共享时长格式化

## 变更内容

- 新增共享的秒数自适应格式化工具，统一日志与首页首字显示。
- 小于 1 秒显示整数毫秒，秒级使用自适应小数精度。
- 超过 1 分钟显示 `1m 05s`，超过 1 小时显示 `1h 01m 05s`。
- 单位边界按四舍五入后自动进位。
- 秒级小数基于整数毫秒舍入，避免 `.005`、`.05` 半值受二进制浮点影响向下偏移。
- 无效值、零值和非流式日志继续显示 `—`。
- 补充首页供应商统计分钟、小时和空值展示的集成测试。
- 未修改 `tokens/s`、总耗时列、后端字段或统计逻辑。
