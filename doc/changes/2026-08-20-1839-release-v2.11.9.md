# v2.11.9 发布

- 变更时间：2026-08-20 18:39:39 CST（Asia/Shanghai）
- 涉及范围：托盘供应商额度错误状态、明暗主题样式、无障碍状态、回归测试、应用版本、全平台构建元数据、发布说明、Git 提交与 Tag

## 变更内容

- 应用版本由 `v2.11.8` 升级为 `v2.11.9`。
- 托盘供应商额度查询失败时，仅显示与首页供应商一致的静态错误图标。
- 错误状态不再显示接口返回的错误信息、金额、进度或重置详情。
- 任意携带 `invalidMessage` 的额度项统一按查询失败处理，并补充无障碍状态播报。
- 同步 `RELEASE_NOTES.md` 与 macOS、iOS、Windows、Linux 构建元数据。
- 补充错误详情隐藏、金额与错误并存、图标结构、无障碍属性及明暗主题样式回归覆盖。

## 验证结果

- 功能完成阶段已通过前端 69 个测试文件共 530 项单元测试及 TypeScript 类型检查。
- 按用户要求，发布阶段不再重复运行测试、构建或 lint。
