# v2.11.7 发布

- 变更时间：2026-08-20 11:09:18 CST（Asia/Shanghai）
- 涉及范围：供应商强制优先状态、代理调度、Gemini 配置保存、首页供应商卡片、前端绑定、应用版本、全平台构建元数据、发布说明、Git 提交与 Tag

## 变更内容

- 应用版本由 `v2.11.6` 升级为 `v2.11.7`。
- 新增供应商强制优先状态，同一平台最多保留一个；可用、模型兼容且会话与并发容量未满时，新会话优先尝试该供应商。
- Claude、Codex、Gemini、自定义 CLI、模型列表和托盘默认供应商预览统一应用强制优先调度；已有会话继续保持原供应商绑定。
- Gemini 新增原子设置接口，失败时整体回滚；前端失败后重新读取服务端状态，避免部分保存造成状态漂移。
- 防止首页图钉按钮快速重复点击；保存期间禁用按钮，失败时恢复状态且不误报成功。
- 强制优先按钮使用高对比蓝色激活态并显示“强制”徽标，补充动态无障碍标签、忙碌状态、指针反馈和亮暗主题键盘焦点样式。
- 复制供应商不继承强制优先状态；增加后端唯一性、原子切换、失败恢复和前端交互回归覆盖。
- 更新 `RELEASE_NOTES.md` 与全平台构建元数据，并通过 `v2.11.7` Tag 触发 GitHub Actions 全平台打包。

## 验证结果

- 功能完成阶段已通过 Go 服务测试、前端 68 个测试文件共 527 项单元测试、TypeScript 类型检查与 `git diff --check`。
- 按用户要求，发布阶段不再重复运行测试、lint、开发服务或完整构建。
