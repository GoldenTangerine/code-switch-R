# 清除请求明细后保留统计汇总

变更时间为 2026-11-20 14:26:22 CST（Asia/Shanghai）。

涉及日志页统计、日志存储清理、会话同步和数据库快照恢复。

## 变更内容

- 「清除明细」在同一数据库事务内按小时、平台、供应商、计价模型和来源归档用量，然后删除逐条请求及其请求体和响应体。月、年查询合并归档和现存明细，显示调用量、成功率、Token、缓存和费用。
- 旧版本已清明细的代理数据可从仍存在的小时汇总恢复调用量、Token、费用及请求结果。能恢复的字段取决于旧汇总保存的数据，模型、单请求峰值和费用分项需要原始明细。
- 会话明细重新导入时使用现有会话回执标记已归档的记录，防止同一笔用量重复计入。实时 QPS 根据当前明细计算。
- 「清除统计」、按日删除和按供应商清理会删除对应的归档。统计清空后，仅在清理新请求明细时归档新用量。恢复旧数据库快照时根据快照中的统计重建可恢复的历史用量。
- 本次修复发布为 `v2.12.1`，同步应用版本、平台构建元数据和 `RELEASE_NOTES.md`。
