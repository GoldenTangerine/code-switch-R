# 发布 v2.10.5

- 变更时间：2026-08-17 18:42:13 CST（Asia/Shanghai）
- 涉及范围：额度查询语义、首页供应商卡片、托盘弹窗、应用版本、全平台构建元数据、发布说明

## 变更内容

- 应用版本由 `v2.10.4` 更新至 `v2.10.5`。
- 修复通用、NewApi 和自定义模板零余额被误判为不限额的问题。
- 仅允许 Sub2API 三个完整且明确为 `0` 的 limit 字段触发不限额状态。
- Sub2API 不满足不限额条件时保留实际余额，避免错误触发额度耗尽。
- 优化首页与托盘长套餐名称显示，并补充进度条辅助语义。
- 同步 macOS、Windows、Linux 与 iOS 构建元数据及发布说明。
- 创建并推送 `v2.10.5` Tag，触发 GitHub 全平台自动打包。
