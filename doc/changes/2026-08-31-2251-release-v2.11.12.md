# v2.11.12 发布

- 变更时间：2026-08-31 22:51:10 CST（Asia/Shanghai）
- 涉及范围：代理调度与负载脱敏、日志仪表盘、Provider 快照、SQLite 写入、前端轮询与设置页加载、拉黑详情交互、应用版本、全平台构建元数据、更新日志、Git 提交与 Tag

## 变更内容

- 应用版本由 `v2.11.11` 升级为 `v2.11.12`。
- 优化代理请求负载脱敏、日志仪表盘聚合和 Provider 快照指纹，保留现有接口、协议、数据格式和用户行为。
- 让 SQLite 连接池逐连接应用现有 `busy_timeout`，并修复事务组返回后的任务切片复用竞态。
- 主窗口隐藏时暂停首页轮询；设置页独立数据并行加载，恢复与卸载生命周期保持可控。
- 统一通用代理尝试状态，保持轮询、降级、黑名单、会话绑定及错误透传语义。
- 优化供应商拉黑详情的悬浮边界、点击固定和长原因滚动展示。
- 新增代理、数据库、日志、快照和前端生命周期的行为矩阵、竞态测试及性能基准。
- 同步 `RELEASE_NOTES.md` 与 macOS、iOS、Windows、Linux 构建元数据。
