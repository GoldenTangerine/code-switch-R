# v2.11.6 发布

- 变更时间：2026-08-20 01:30:58 CST（Asia/Shanghai）
- 涉及范围：Claude、Codex、Gemini、自定义 CLI 会话粘滞路由、托盘默认供应商预览、应用版本、全平台构建元数据、发布说明、Git 提交与 Tag

## 变更内容

- 应用版本由 `v2.11.5` 升级为 `v2.11.6`。
- 新会话尚未绑定供应商时，首页排序第一的当前可用供应商若为零会话，则跨 Level 优先尝试。
- 首位供应商已有临时或确认会话后，恢复原有 Level、会话容量和负载排序；既有会话继续使用原绑定。
- 并发新会话在会话锁内复核首位供应商的零会话条件并创建临时绑定，避免多个新会话同时抢占首位。
- 首位不可用、拉黑、配置无效、模型不兼容或请求失败时，保留原有过滤、重试和降级行为。
- Claude、Codex、Gemini、自定义 CLI 与托盘默认供应商预览统一使用相同规则。
- 更新 `RELEASE_NOTES.md`，同步全平台构建元数据，并通过 `v2.11.6` Tag 触发 GitHub Actions 全平台打包。

## 验证结果

- 功能完成阶段已通过目标测试、Provider/Gemini 并发用例连续运行、竞态检测、Go 服务全量测试、`go vet` 与 `git diff --check`。
- 按用户要求，发布阶段不再重复运行测试、lint、开发服务或完整构建。
