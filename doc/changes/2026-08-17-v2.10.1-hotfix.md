# v2.10.1 白屏修复

- 变更时间：2026-08-17 CST（Asia/Shanghai）
- 版本：v2.10.0 → v2.10.1
- 类型：hotfix

## 问题

v2.10.0 打包发布后，主界面与托盘两个窗口在首次启动时整体白屏，无任何 UI 渲染；开发模式（`wails3 task dev`）下不复现。

## 根因

新增的 `openClaw.ts`、`hermes.ts`、`pi.ts` 三个服务文件静态导入了 Main 适配器（`components/Main/adapters/providerCardMappers`），其中 `normalizeProviderRef` / `cardProviderRef` / `normalizeProviderKey` 等函数来自 Main 适配器侧，形成 `app-services` chunk 与 `main-page` chunk 的循环依赖。生产构建启用 `manualChunks` 分包后，整个 `main-page` 代码块被拖入两窗口的启动求值链，初始化顺序异常导致渲染失败白屏；dev 模式未启用 manualChunks，单 bundle 下循环依赖不触发时序问题，故不受影响。

## 修复

- 将 `normalizeProviderRef` / `cardProviderRef` / `normalizeProviderKey` 三个纯函数下沉至叶子模块 `frontend/src/utils/providerRefs.ts`，服务层改为从该 utils 模块导入，切断 `services` → `components` 的跨 chunk 依赖，主页面恢复路由懒加载。
- `frontend/src/main.ts` 启动链增加兜底 `catch`：初始化异常时渲染可见错误面板而非无声白屏。
