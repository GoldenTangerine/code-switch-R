# 首页供应商事件定位调整

- 变更时间：2026-08-27 10:22:44 CST（Asia/Shanghai）
- 涉及范围：首页供应商列表、供应商切换与拉黑事件、前端单元测试

## 变更内容

- 移除供应商事件高亮时的卡片自动居中滚动及相关 DOM 引用链路。
- 供应商切换或拉黑事件不再自动切换平台 Tab。
- 非当前 Tab 的事件仅更新最后使用供应商与黑名单状态，不触发隐藏卡片高亮。
- 当前 Tab 的供应商事件继续保留 3 秒卡片脉冲高亮，其他事件同步行为不变。
- 补充切换与拉黑事件在当前、非当前 Tab 下的回归测试。
