# macOS 27 托盘弹窗兼容修复

- 变更时间：2026-08-10 10:27:32 CST（Asia/Shanghai）
- 涉及范围：Wails 运行时、macOS 托盘窗口、Darwin 构建任务、发布工作流、Linux GTK3 兼容链路

## 变更内容

- 将 Wails 从 `v3.0.0-alpha.38` 升级到 `v3.0.0-beta.6`；后续复核确认 beta.6 未包含 macOS 27 托盘输入修复，原判断有误。
- 将 `@wailsio/runtime` 锁定为 `3.0.0-beta.5`，并重新生成前端绑定。
- 将 Go 最低版本升级到 `1.25`，同步发布工作流和开发文档。
- 适配 beta runtime 的 `WailsEventCallback` 事件类型和可选 map 绑定类型，保持现有业务数据结构不变。
- 按 beta.6 官方生成模板将 macOS 最低版本统一为 `12.0`，避免 plist 与编译参数不一致。
- Darwin 构建保留 beta.6，仅在临时 module 副本中移植 Wails 官方 PR `#5760` 的托盘补丁：macOS 27 使用 `NSGestureRecognizer` 和 `performClick:`，macOS 26 及以下继续使用原 `NSEvent` 路径。
- 托盘窗口显示后的 `300ms` 内忽略首次失焦事件，避免状态栏鼠标事件尚未结束时窗口被立即隐藏；保护期结束后继续保持原有失焦关闭行为。
- Linux 继续使用 `gtk3` 兼容标签，并使用独立 nFPM 配置保留 GTK3/WebKit2GTK 4.1 运行时依赖。
- GitHub Release 工作流校验 macOS 27 补丁与 Darwin `modfile` 接入，并继续校验 Linux GTK3 构建标签、独立 nFPM 配置和运行时依赖。
