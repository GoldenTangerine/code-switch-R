# CodeNotch 托盘联动

变更时间：2026-09-08 17:18:00（Asia/Shanghai）。

涉及范围：Code Switch R 应用生命周期、托盘供应商数据、共享快照服务；CodeNotch 文件读取、动态列表、详情展示及设置。

## 变更内容

- 后台维护与托盘共用的供应商、额度及今日统计快照，脱离弹窗焦点运行。
- 在 macOS 原子发布只含展示数据的快照，加入会话、递增序号、心跳和正常退出清理。
- 托盘消费统一快照，保留平台预算查询；CodeNotch 原有供应商在前、联动供应商在后，断开隐藏并自动恢复。
- 增加额度、余额、调用状态与统计详情，以及默认开启的联动设置。
- 增加 Go、前端和 Swift 回归用例及联动说明。

## 验证结果

- Go 快照与关联供应商、预算、统计回归通过；应用入口的定向测试通过，快照 `-race` 检查通过。
- 托盘类型检查和 42 项托盘单元测试通过。
- CodeNotch 全源码在 macOS 26.5 SDK 下通过 Swift 类型检查，并编译运行独立联动验证程序。
- 独立程序验证协议、文件创建与原子替换、心跳过期、删除、恢复、关闭开关、排序和悬停；模拟文件出现到读取约 0.69 秒。AppKit 承载视图确认详情内容正常渲染。
- 本机没有完整 Xcode、XCTest 和 xcodegen，未执行正式 `make test`，未打包或替换已安装应用。没有使用真实供应商凭据进行双应用运行验收。
