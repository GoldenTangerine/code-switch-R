# 发布 v2.9.23

- 变更时间：2026-08-10 11:06:53 CST（Asia/Shanghai）
- 涉及范围：macOS 托盘、Wails 运行环境、前端绑定、Linux GTK3 打包、GitHub Actions、版本元数据与发布说明

## 变更内容

- 升级 Wails 至 `v3.0.0-beta.6`，恢复 macOS 27 状态栏托盘窗口的置顶和显示行为。
- Go 最低版本升级至 1.25，前端 runtime 锁定为 `3.0.0-beta.5`，同步重新生成全部前端绑定。
- Linux 保留 GTK3 构建标签，DEB、RPM 与 AUR 使用独立 nFPM 配置并声明 GTK3/WebKit2GTK 4.1 依赖。
- GitHub Release 工作流同步工具链版本，并在 Linux 打包前校验 GTK3 构建与打包配置。
- 应用版本推进至 `v2.9.23`，同步全平台构建元数据和发布说明，通过 `v2.9.23` Tag 触发 GitHub 自动打包。
