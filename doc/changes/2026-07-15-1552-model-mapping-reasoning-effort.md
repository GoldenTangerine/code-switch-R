# 模型映射强制思考强度

- 变更时间：2026-07-15 15:52:08 CST（Asia/Shanghai）
- 涉及范围：首页供应商编辑、模型映射、Claude/OpenAI 请求转换、请求日志

## 变更内容

- 为 Claude、Codex、其他供应商的每条模型映射增加可选思考强度，支持 `low`、`medium`、`high`、`xhigh`、`max` 和自定义值。
- 留空时保留请求原有强度；请求未开启思考且没有强度字段时不新增字段。
- 按上游协议写入 `output_config.effort`、`reasoning_effort` 或 `reasoning.effort`，OpenAI 格式下将 `max` 转为 `xhigh`。
- 模型映射强度优先于供应商请求体强制字段，并在请求日志中记录最终强度来源。
- 日志模型提示增加强度与来源信息，历史记录来源为空时显示未记录。
- 请求计划统一记录最终强度、来源、目标字段和模型映射实际应用状态，兼容重试移除字段后同步刷新日志。
- 已记忆上游不支持的可选思考字段会在模型映射注入后统一清理，避免后续请求重复触发兼容性错误。
- 请求体覆盖来源按最终生效的思考控制字段判断，预算覆盖会正确标记，低优先级字段不会抢占来源。
- 模型映射编辑的重命名、删除和清空强度改为统一状态操作，并增加不可变性回归测试。
- `minimal` 作为有效自定义强度参与覆盖和日志记录；Gemini 请求日志同步记录请求或请求体覆盖来源。
- 自定义强度标签增加最大宽度、溢出省略和完整值提示，避免长文本挤压映射操作区。
