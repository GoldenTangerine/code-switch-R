# 剪贴板复制与手动选择兜底

- 变更时间：2026-08-19 20:50:00 CST（Asia/Shanghai）
- 涉及范围：日志请求详情、供应商日志、模型调试详情、控制台错误、额度错误、Codex OAuth 复制

## 变更内容

- 日志请求详情的请求/响应原文与格式化复制统一使用公共剪贴板工具，避免 WebView 拒绝浏览器 Clipboard API 时直接失败。
- 模型调试详情与 Codex OAuth 复制移除重复剪贴板写入逻辑，统一优先使用 Wails 原生剪贴板并保留既有降级能力。
- 公共剪贴板工具识别 `Arch: browser` 预览环境，避免无效 Wails Runtime 请求；全部复制方式失败时同时保留底层错误与降级错误。
- textarea 降级复制增加无 DOM 检查与异常清理，避免临时节点残留。
- 日志正文、供应商错误、模型调试信息、控制台错误、额度错误及 OAuth 可见内容支持鼠标自由选择，可使用系统快捷键手动复制。
- 模型调试与 OAuth 的文本选择样式收窄到内容区域，避免操作按钮参与拖选。
- 清理不再使用的中英文剪贴板不可用文案键。
- 新增日志载荷详情回归测试，覆盖请求/响应原文、格式化内容及详细失败提示。
