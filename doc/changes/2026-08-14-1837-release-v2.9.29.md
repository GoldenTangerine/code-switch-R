# 发布 v2.9.29

- 变更时间：2026-08-14 18:37:07 CST（Asia/Shanghai）
- 涉及范围：Claude 代理路由、会话供应商偏好、并发调度、请求日志、前端详情展示、版本元数据与 GitHub Actions

## 变更内容

- Claude 模型路由开启且请求具有稳定会话标识时，Subagent 优先跟随当前会话主请求最近成功的供应商。
- 会话首选供应商跨 Level 绝对优先；首选不可用或失败后，继续按原有 Level 与轮询顺序降级。
- 并发主请求使用 generation 管理临时偏好，失败回滚，旧请求成功不覆盖更新状态；并发槽拒绝时不发布偏好。
- 会话缓存限制为最多 4096 个非活动会话，活动连接与请求日志增加首选供应商及选择结果字段。
- 未识别模型、缺少稳定会话标识或未开启模型路由时保持原有行为。
- 应用版本推进至 `v2.9.29`，同步构建配置和发布说明，准备通过 `v2.9.29` Tag 触发 GitHub 全平台自动打包。
