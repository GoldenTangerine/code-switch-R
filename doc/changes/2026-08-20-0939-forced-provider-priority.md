# 变更名称

供应商强制优先

# 变更时间

2026-08-20 09:39:02（Asia/Shanghai）

# 涉及范围

- 后端供应商配置持久化与代理调度
- Claude、Codex、Gemini 及自定义 CLI 供应商路由
- 首页供应商卡片与中英文文案
- Wails 前端模型绑定

# 变更内容

- 为本地代理供应商增加强制优先状态，同一平台最多保留一个。
- 强制供应商在启用、未拉黑、模型兼容且会话容量未满时优先尝试。
- 已绑定会话继续优先原供应商；原供应商失败、拉黑或模型不支持时再切换到强制供应商和后续规则供应商。
- 强制供应商失败不会自动取消状态；固定拉黑模式按失败阈值重试后再降级。
- `/v1/models`、托盘默认供应商预览及自定义 CLI 路由同步强制优先顺序。
- 首页新增图钉按钮和“强制”徽标，激活态使用高对比蓝色；代理关闭或供应商不可用时禁止新设。
- 图钉保存期间禁用全部强制优先按钮，快速重复点击只执行一次保存；保存占用时恢复本地状态且不提示成功。
- Gemini 强制优先切换改为单次原子写入，失败时后端回滚并由前端重新读取真实状态。
- 图钉按钮补充动态无障碍标签、忙碌状态、指针反馈及亮暗主题键盘焦点圈。
- 复制供应商不继承强制优先状态。
- 增加并发保存、Gemini 原子切换与回滚、持久化唯一性和按钮可访问性的回归测试。
