# 发布 v2.9.14

- 变更时间：2026-07-23 17:34:27 CST（Asia/Shanghai）
- 涉及范围：首页供应商卡片、黑名单状态、成功率提示、前端测试、版本元数据、发布说明与 GitHub Actions

## 变更内容

- 首页供应商卡片不再直接展示请求失败计数和巡检失败计数，计数及阈值移入成功率悬浮提示。
- 活跃拉黑状态改为在花费指标后显示剩余倒计时，点击可查看触发来源、原因及解除拉黑、清零等级操作。
- 阈值请求支持并发复用和 60 秒缓存；请求失败或非法响应时不伪造默认阈值。
- 窄屏浮层定位、拉黑状态排版及英文触发来源文案完成优化。
- 新增前端单元测试，覆盖供应商卡片和黑名单状态边界行为。
- 应用版本推进至 `v2.9.14`，同步构建元数据并通过 `v2.9.14` Tag 触发 GitHub 全平台自动打包。
