# 首页未启用供应商卡片灰度样式

- 变更时间：2026-08-31 11:15:18 CST（Asia/Shanghai）
- 涉及范围：首页供应商列表、供应商卡片明暗主题样式、前端单元测试

## 变更内容

- 为未启用供应商卡片增加独立的 `is-disabled` 状态类，与启用状态互斥。
- 未启用卡片在亮色和暗色主题下使用中度灰度背景、边框、阴影与文字配色。
- 降低未启用卡片品牌图标及非告警徽标的饱和度，悬停时继续保持灰度。
- 保留操作按钮、额度提示、告警状态以及拖拽和事件高亮反馈。
- 手动停用与额度自动停用统一使用未启用灰度样式。
- 额度自动停用卡片保留橙色边框与左侧强调线，不受中性停用边框覆盖。
- 压暗暗色主题下的未启用卡片背景，避免未启用卡片比启用卡片更突出。
- 补充额度自动停用样式优先级回归测试。
