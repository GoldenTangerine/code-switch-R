# 供应商首速统计口径调整

- 变更名称：供应商首速统计口径调整
- 变更时间：2026-07-13 17:49:13 CST
- 涉及范围：流式请求首字采集、日志性能列速度、首页供应商首速统计

## 变更内容

- 首字采集按响应协议识别首个有效流式输出，排除 OpenAI/Codex 前置事件、usage-only 和终态事件。
- Claude 和自定义 Anthropic 透传以首个非空 data 事件记录首字；Gemini 支持文本与工具调用内容。
- 日志速度改为 `output_tokens / duration_sec`，不再减去首字耗时，不再使用 50ms 最小窗口。
- 首页首速跨天取每个供应商最近 5 条成功、流式、字段完整的请求，首字与单条速度分别取算术平均。
- 当天请求数、Token、费用仍按当天统计；失败请求不进入首页性能样本。
- 保留日志独立耗时列，不在性能列重复增加总耗时。
- 更新中英文首页性能口径提示。
