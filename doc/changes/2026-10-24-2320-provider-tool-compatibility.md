# 供应商工具兼容

- 变更时间：2026-10-24 23:20:14（Asia/Shanghai，UTC+08:00）。
- 涉及范围：供应商配置及快照、Claude 请求计划与请求头、供应商表单及卡片转换、编辑弹窗、中英文文案和回归测试。

## 变更内容

- 新增供应商独立的 `toolCompatibility` 配置：`disabledNames`、`disabledTypes`、`normalizeDynamicTools`。默认不启用；名称与类型均按区分大小写的精确值匹配，不支持通配符。
- Claude 编辑弹窗在请求体强制字段之前显示工具兼容区域：双列名称／类型输入，支持换行或逗号分隔；窄屏改为单列，使用现有明暗主题变量，开关支持键盘操作。
- “填入 Advisor 兼容预设”合并 `advisor` 名称和 `advisor_20260301` 类型，并启用动态工具兼容，不覆盖用户已有规则，也不自动修改本地供应商配置。
- 过滤在 `/v1/messages` 输入的请求体强制覆盖之后、协议转换之前执行，因此适用于原生 Anthropic 和 Claude 转 OpenAI 的代理路径。Codex Responses 和 Chat 输入不做此处理；直连不会经过本应用过滤。
- 被禁用工具的定义和动态引用移除；已有工具调用及其匹配结果转换为带说明的普通文本，保留历史数据。强制选中被禁用工具的 `tool_choice` 移除，正常工具调用与结果保持配对。
- 动态工具兼容将内联定义加入普通工具列表、删除 `defer_loading`，移除动态添加／移除和工具引用块；嵌套工具结果被清空时保留普通文本结果。所有保留工具直接可用，不再按历史位置动态隐藏工具。
- 动态兼容将中途 system 消息降为 user 消息以兼容普通 Messages 接口，保留其文本；移除因此清空的消息，同时清理 `mid-conversation-*` 和 `inline-tools-*` beta 标记，保留 1M 等其他标记。这属于显式启用的协议降级，不保证原动态工具协议的权限和时序语义。
- 每个供应商独立解码请求，不修改原始请求及其他供应商的重试输入。供应商快照深拷贝配置数组；表单保存、卡片读回保留配置。控制台仅输出处理的工具名称与动态兼容标记，不输出工具参数和对话内容。
