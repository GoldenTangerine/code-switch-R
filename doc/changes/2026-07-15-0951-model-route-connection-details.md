# 连接详情模型路由展示

- 变更时间：2026-07-15 09:51:32 CST（Asia/Shanghai）
- 涉及范围：首页供应商连接详情、Claude 模型路由、活跃连接状态、请求日志、SQLite 兼容迁移

## 变更内容

- Claude 模型路由开启时，供应商连接详情中的活跃连接与历史连接固定展示“请求模型”和“实际模型”。
- 实际模型作为主信息加粗；悬停或键盘聚焦后展示当次命中的映射规则、映射结果及 `RequestBodyOverrides.model` 覆盖过程。
- 未发生改写的新请求显示明确提示；迁移前历史日志显示“未记录模型路由信息”，不按当前供应商配置反推。
- 活跃连接与请求日志新增模型路由快照字段，记录请求发生时的映射源规则、目标规则、中间模型、模型覆盖和采集状态。
- `request_log` 自动补齐模型路由列，旧数据保持默认值并继续兼容查询。
- 路由关闭，或平台为 Codex、Gemini、自定义 CLI 时，连接详情保持原有单模型布局。
- Tooltip 使用视口固定定位并自动选择上下方向，避免被弹窗滚动区域裁切。
- 无障碍标签包含实际模型和完整路由过程，键盘聚焦时不会丢失模型 ID。
- Tooltip 的全局滚动与缩放监听仅在浮层可见时注册，关闭后立即清理。
- 模型覆盖解析移除无效参数，并新增真实转发、批量落库、日志查询读回的完整往返测试。
- 模型路由提示文案抽取为纯函数，覆盖旧日志、未改写、映射覆盖及无障碍标签场景。
- 当模型经过映射和覆盖后回到请求模型时，仅展示真实改写链，不再追加“未发生模型改写”的矛盾提示。
