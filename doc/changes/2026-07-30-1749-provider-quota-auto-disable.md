# 供应商额度耗尽自动停用

- 变更时间：2026-07-30 17:49:44 CST（Asia/Shanghai）
- 涉及范围：应用设置、供应商额度查询、Claude/Codex/Gemini/OpenCode/自定义 CLI 供应商状态、代理错误触发、首页卡片

## 变更内容

- 新增“额度耗尽自动停用”全局开关，默认关闭。
- 任一有效远端额度项耗尽时自动停用供应商；官方余额返回 `Active=false` 的零余额同样识别为耗尽，所有有效项恢复后自动启用。
- 查询失败、空结果、无效额度项和旧缓存不改变供应商状态。
- 自动停用、手动关闭和临时启用使用独立持久化状态，手动关闭不会被自动恢复。
- 自动停用卡片显示“额度用完”和“临时启用”，临时启用后可“恢复自动”。
- 自动停用卡片投影到启用组末尾，并保留原启用顺序，额度恢复后回到原位置。
- 关闭全局开关或移除额度配置时恢复自动停用项并清除暂停状态；应用启动时会校正关闭开关下的残留自动状态。
- Claude、Codex、Gemini 上游非 2xx 响应按供应商异步触发额度检查，同一供应商 30 秒内合并触发。
- OpenCode 状态变化同步 live 配置；首页额度刷新负责各平台的停用与恢复检测。
- OpenCode 供应商副本不继承自动停用或暂停状态，避免副本被额度刷新意外启用。
- 自动停用供应商禁止卡片直接应用及“保存并应用”；额度状态事件仅更新目标平台的目标卡片。
