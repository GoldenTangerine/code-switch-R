# 模型下拉虚拟化

- 变更时间：2026-07-21 16:18:57 CST（Asia/Shanghai）
- 涉及范围：共享模型搜索输入、候选搜索、键盘交互与前端测试

## 变更内容

- 模型候选弹层传送到页面顶层并使用固定定位，不再被模型映射容器裁剪；外部滚动或窗口尺寸变化时关闭。
- 候选达到 8 条时至少完整显示 8 行，候选较少时按内容高度显示。
- 使用固定行高虚拟窗口，仅渲染可视候选和缓冲项，保留全部模型、键盘导航与 ARIA 组合框语义。
- 候选列表建立复用搜索索引，查询即时生效，保持原有模糊匹配规则和排序，避免选中延迟过滤前的旧候选。
- 下拉根据视口剩余空间自动向上或向下展开；空间不足时限制高度并保留 12px 视口边距。
- 模型输入禁用系统与第三方写作建议，并阻止 `insertReplacementText` 自动替换事件。

## 问题修正

- 根因：当前 `@headlessui/vue 1.7.23` 声明了 `virtual` 属性，但本地运行时构建未启用对应上下文；类型检查无法发现插槽不会提供候选值。
- 修正：共享模型输入改为自有虚拟窗口，不再依赖未生效的运行时能力，也不新增第三方依赖。
- 预防：新增下拉高度、视口翻转、虚拟窗口和键盘索引计算测试；运行时能力不能再仅凭类型声明判断。
