# v2.11.5 发布

- 变更时间：2026-08-19 23:01:35 CST（Asia/Shanghai）
- 涉及范围：Codex 代理会话识别、会话粘滞、请求日志、首页连接详情、应用版本、全平台构建元数据、发布说明、Git 提交与 Tag

## 变更内容

- 应用版本由 `v2.11.4` 升级为 `v2.11.5`。
- 修复 Cursor 使用 API 代理调用 Codex 时同一会话在多个供应商间切换的问题，Responses 请求可通过 `prompt_cache_key` 保持稳定会话身份。
- 统一 Cursor、Codex 显式线程/会话、父级与根级标识的归一优先级，消除自引用并保留请求体与请求头合并后的会话树关系。
- 会话来源统一从入口原始请求体识别，避免供应商请求体覆盖或协议转换改变粘滞结果。
- 请求日志新增会话识别来源，首页连接详情的活跃和历史记录同步显示适配亮暗主题的来源标签。
- 旧数据库自动迁移来源字段，仅保存来源类型和会话 Hash，不保存原始会话 ID 或缓存键。
- 更新 `RELEASE_NOTES.md`，同步全平台构建元数据，并通过 `v2.11.5` Tag 触发 GitHub Actions 全平台打包。

## 验证结果

- 功能完成阶段已通过 Go 服务测试、前端 68 个测试文件共 519 项单元测试、TypeScript 类型检查与 `git diff --check`。
- 按用户要求，发布阶段不再重复运行测试、lint、开发服务或完整构建。
