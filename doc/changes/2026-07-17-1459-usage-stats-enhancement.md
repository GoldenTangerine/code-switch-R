# 日志用量统计增强

- 变更时间：2026-07-17 14:59:31 CST（Asia/Shanghai）
- 涉及范围：日志统计后端、日志页面、应用设置、国际化与测试

## 变更内容

- 日志页新增“请求明细 / Provider 统计 / 模型统计”三个数据视图，统计表支持按指标排序并默认按成本降序。
- 新增全局计价模型筛选，统一按 `matched_pricing_model` 优先、`model` 回退的口径过滤明细、汇总、趋势与统计数据。
- 请求明细以计价模型为主信息，并补充请求、映射、响应和路由模型链路。
- Provider 统计新增平均耗时；模型统计新增单次均价展示。
- 自动刷新支持关闭、5、10、30、60 秒档位，默认 30 秒并持久化；底部数据视图使用本地存储记忆。
- 补充后端聚合、设置持久化、前端筛选、自动刷新与数据加载测试。

## 评审修正

- 修正动态补价可能改变模型分组口径的问题，新增稳定的有效计价模型响应字段，使 SQL 筛选、统计分组和请求主展示保持一致。
- 自动刷新改为单任务执行，并在其他日志加载进行中跳过轮询，避免短周期刷新叠加请求。
- 加载状态覆盖整批仪表盘请求及分页请求，避免统计尚未完成时提前显示为加载结束。
- Provider 变化时立即级联模型选项，并防止已应用查询的自动刷新覆盖正在编辑的筛选选项。
- 模型单次均价使用六位小数；Provider 统计仅在对应 Tab 激活时加载，减少无用聚合扫描。
- 修正时间：2026-07-17 15:35:14 CST（Asia/Shanghai）。

## 根因与防复发

- 根因属于跨层口径和异步状态边界不一致：数据库筛选使用存储字段，读取补价会改写响应字段；多个并行请求却共享单一明细加载状态。
- 通过独立的有效计价模型字段、统一参数化 SQL 表达式、整批加载计数和刷新互斥从结构上约束行为。
- 回归测试覆盖动态补价、空白模型值、长时间刷新、统计延迟、草稿筛选竞态和 Provider 按需加载。
