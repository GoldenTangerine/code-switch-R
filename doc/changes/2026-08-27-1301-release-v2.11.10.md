# v2.11.10 发布

- 变更时间：2026-08-27 13:01:32 CST（Asia/Shanghai）
- 涉及范围：首页供应商列表、供应商切换与拉黑事件、前端单元测试、应用版本、全平台构建元数据、发布说明、Git 提交与 Tag

## 变更内容

- 应用版本由 `v2.11.9` 升级为 `v2.11.10`。
- 供应商切换或拉黑事件到达时，页面停留在当前平台 Tab，不再自动切换到事件对应的平台。
- 移除供应商事件高亮时卡片自动滚动居中的逻辑及 `bindCardRef` DOM 引用链路（`Index.vue` → `ProviderCardGrid.vue` → `ProviderCard.vue`）。
- 非当前 Tab 的供应商事件仅更新最近使用供应商与黑名单状态，不触发隐藏卡片高亮；当前 Tab 继续保留 3 秒脉冲高亮。
- 补充切换与拉黑事件在当前、非当前 Tab 下的定位行为回归测试。

## 验证结果

- 功能完成阶段已通过前端 69 个测试文件共 534 项单元测试及 TypeScript 类型检查。
- 按项目限制，发布阶段不再重复运行测试、构建或 lint。

## 发布

- 创建提交 `🦄 fix(release): 取消供应商事件自动定位切换并发布 v2.11.10`。
- 推送 `v2.11.10` Tag 触发 GitHub Actions 全平台自动打包。
