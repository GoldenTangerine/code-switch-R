# 发布 v2.10.0

- 变更时间：2026-08-17 08:12:10 CST（Asia/Shanghai）
- 涉及范围：供应商存储、代理路由、多应用供应商管理（Grok Build / Claude Desktop / OpenClaw / Hermes / Pi）、OpenCode 增强、MCP / Skill / Prompt 资源页、用量统计、版本元数据

## 变更内容

- 供应商存储统一迁移至 SQLite（providers_store 单表 + 事务式 JSON 迁移 + 失败自动恢复 + nil/空哨兵语义）。
- 新增 Grok Build 供应商管理：config.toml 管控、:18100 代理路由复用降级轮询黑名单、xAI OAuth 设备码流托管登录、updates.jsonl 会话用量采集。
- 新增 Claude Desktop 供应商管理：四文件事务式写入回滚、直连/代理双模式、网关 token 与模型路由。
- 新增 OpenClaw / Hermes / Pi 供应商管理：additive 共存模式，OpenClaw 含环境变量/工具/Agents 专属配置页，Hermes 含记忆管理页。
- OpenCode 升级：预设头部化清洗、MCP/Skill/Prompt 投影、opencode.db 用量采集。
- MCP / Skill / Prompt 资源页扩展至全平台；首页 tab 自适应显示；新增三应用品牌图标。
- 自研 JSON5 归一化、Hermes YAML Node 保真读写、双源会话用量统计。
- 修复代码审查发现的 3 个 P0 与 18 个 P1，新增及扩展测试 88 项。
- 应用版本推进至 `v2.10.0`，同步构建配置和发布说明，准备通过 `v2.10.0` Tag 触发 GitHub 全平台自动打包。
