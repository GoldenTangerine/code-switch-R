# Codenotch 按需全量供应商联动

变更时间：2026-09-10 17:35:00（Asia/Shanghai）。

涉及范围：`main.go`、`services/traysnapshotservice.go`、`services/customcliservice.go`、新增 `services/codenotch_integration.go` 及回归基准、`RELEASE_NOTES.md`；配套 Codenotch 的独立设置页、后台接收和隐藏偏好。

## 变更内容

- 原 `tray-snapshot-v1.json` 的平台选择和版本保持兼容，增加可选 `codenotch` 元数据。额外供应商写入 `codenotch-providers-v1.json`，通过发布者 session 和 revision 配对。
- 消费者在 `codenotch-subscription-v1.json` 每 5 秒续约；仅 version=1、mode=enabled、有效 session 且心跳不超过 15 秒时生效。文件限定在 `~/Library/Caches/code-switch`，使用私有原子写入。
- 约每秒枚举一次代理托管状态与供应商开关，包含隐藏平台、自定义 CLI 和 Claude Desktop；供应商是否正在请求不影响入选。复用并发计数，不为全量查询重复计算托盘默认供应商。
- 全量内容未变化不序列化/写入，文件删除后自动重建；主文件继续发布小元数据。单文件上限 2,000,000 字节，订阅上限 4096 字节，超限报错而非截断。
- 托盘与全量需求合并到同一配额缓存和最多 4 个 worker；60 秒后可再次刷新，先调度最久未调度项。按平台缓存日统计并建立 ID/名称索引，避免供应商间重复查询及线性匹配。
- 撤销/过期后取消额外查询、移除自己的全量文件并回收输入和统计缓存；共享托盘任务继续运行。请求序号阻止旧任务覆盖新查询，复合身份避免含分隔符的 ID 冲突。
- Codenotch 的逐个隐藏仅控制展示和关联会话，不更改此端的供应商开关或查询需求；普通 hooks 和本地账户独立工作。

## 评审修正

- 供应商短暂离开托盘后，保留仍在 60 秒有效期内的查询结果；非当前需求缓存上限 128 条，淘汰最久未展示项。立即取消移出需求的查询，丢弃迟到结果，不额外保留查询输入；仅全量模式产生的缓存撤销后仍立即回收。
- 全量文件通过文件身份、大小及修改时间发现外部改写，删除或损坏后自动重新发布并推进修订；正常稳态只检查属性，不每秒重读整份文件。
- 自定义 CLI 复用本轮工具列表检查各目标配置，保留原有公共 ProxyStatus API、鉴权字段和旧 token 兼容行为；下一轮响应目标文件、工具配置与删除变更。
- 接收端隐藏全部联动供应商后保留独立本地占位入口；可选扩展字段异常时保留基础托盘协议的正常数据。

## 验证结果

- Go `TestHookSession*`、`TestTray*`、`TestCodenotch*` 定向测试和 race 检查通过；主包编译通过。
- Codenotch 全应用源码通过 SDK 26.5 编译，69 项 Swift 回归通过；覆盖模式协商、旧版升级、修订错误恢复、快速启停、撤销归属、隐藏持久化、会话过滤和可选扩展容错。
- 评审修正后的 Go 定向 race 测试与主包编译通过；新增真实本地 HTTP 查询计数、TTL 到期与配置失效、128 条保留上限、取消后迟到结果、原地/等长/原子改写恢复以及自定义 CLI 配置更新回归。
- 新增动态采集基准：10/100/500 个 Codex 供应商加 10 个真实合成配置的自定义工具，逐轮轮换请求与会话归属、每 10 轮编辑工具配置；中位采集耗时约 0.447/0.463/0.921 毫秒，逐轮恰好发布一次全量文件。未包含远程配额或统计查询耗时。
- 自定义 CLI 检查 100 个工具的对照基准中，每轮整表重读耗时约 28.61 毫秒，复用配置后约 1.63 毫秒；分配量从约 11.82 MB 降至 0.36 MB。两组读取相同的合成工具和目标文件，各 100 轮重复 3 次。
- M4/macOS 上，10/100/500 供应商各 1000 次稳态采集的三次运行中位耗时约 0.019/0.055/0.220 毫秒；未变列表始终只写一次。
- 1000 次全量启停各重复三轮，验证每轮取消后额外缓存为空。三种规模中位耗时约 0.396/0.634/1.534 毫秒/轮。
- Go 基准测试进程整体峰值 RSS 48,431,104 字节；不包含 Wails 窗口，也不是本功能独占内存。测试使用独立临时目录与测试数据库，没有真实供应商网络查询。
- Codenotch 的 500 供应商全量快照重复读取 1000 次，完整数据解码仅 1 次，读取 CPU 时间约 83 毫秒。此为隔离文件基准，不代表真实 UI 帧率或第三方接口耗时。
- 开发阶段未运行 Wails 打包；当前环境无桌面屏幕，未完成两端真实窗口交互验收。
