# 供应商模型搜索下拉框

## 变更时间

2026-07-16 01:45:20 CST（Asia/Shanghai）

## 涉及范围

- 首页供应商编辑
- 模型映射
- 内置模型候选

## 变更内容

- 供应商模型输入框支持自由输入、下拉选择和模糊筛选。
- 下拉候选聚合内置、Claude 同步和云端同步的普通模型名，不包含手动定价模型及带供应商前缀的模型标识。
- 下拉选择仅填入供应商模型，保留手动输入后的回车提交行为。
- CLI 模型选择后继续自动聚焦供应商模型输入框。
- 修复 Enter 被外层监听器提前阻止，导致键盘高亮候选无法选中的问题。
- 为候选选择与自定义值提交的 Enter 分流增加回归测试。
