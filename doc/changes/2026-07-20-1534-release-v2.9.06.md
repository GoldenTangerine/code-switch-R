# 发布 v2.9.06

- 变更时间：2026-07-20 15:34:48 CST（Asia/Shanghai）
- 涉及范围：全局可搜索模型输入框、模型映射与 CLI 模型交互、应用版本、Wails 平台构建元数据、GitHub Release 更新说明

## 变更内容

- 版本号由 `v2.9.05` 推进到 `v2.9.06`。
- 输入内容匹配候选项时，Tab、失焦或直接按 Enter 不再自动写入首个匹配项。
- 仅鼠标点击候选或键盘明确导航后按 Enter 才会写入候选。
- 修复输入法合成 Enter 误触发切换焦点、提交映射或应用配置的问题。
- 失焦、完成选择或输入变化后完整清理选择意图，避免后续 Enter 无响应或错误选中。
- 补齐 Home、End、PageUp、PageDown 候选导航及连续交互回归测试。
- 更新 `RELEASE_NOTES.md`，供 GitHub Actions 按 `v2.9.06` 提取本次版本说明。
- 同步 macOS、Windows、Linux 构建元数据，并通过推送 `v2.9.06` Tag 触发全平台自动打包。
