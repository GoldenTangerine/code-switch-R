# 供应商额度错误悬浮窗

- 变更时间：2026-08-17 16:22:11 CST（Asia/Shanghai）
- 涉及范围：首页供应商卡片、悬浮窗布局工具、国际化文案与回归测试

## 变更内容

- 额度查询失败时只显示单个圆形感叹号入口，避免完整错误文本撑开卡片。
- 保留额度更新时间和刷新按钮；点击错误图标后汇总展示全部完整错误信息。
- 错误悬浮窗支持再次点击、点击外部和 `Esc` 关闭，并与黑名单悬浮窗互斥。
- 悬浮窗通过 `Teleport` 固定到视口层，自动处理上下翻转、左右边界和小视口最大高度，避免被卡片容器裁剪。
- 弹窗打开时暂停卡片拖拽，弹窗内部阻止拖拽事件，避免选择错误文本触发卡片排序。
- 切换平台或卡片身份时自动关闭弹窗，避免复用相同卡片 ID 时泄漏打开状态。
- 补充明暗主题、长文本换行、键盘焦点恢复和动态 ARIA 状态。
- 新增组件与布局回归测试，覆盖紧凑错误展示、右侧边界、底部翻转和小视口约束。
