# 发布 v2.10.2

- 变更时间：2026-08-17 11:07:19 CST（Asia/Shanghai）
- 版本：v2.10.1 → v2.10.2
- 涉及范围：首页供应商 Tab、通用设置、应用设置服务、全平台构建元数据与发布说明

## 变更内容

- 修复 Grok Build、Claude Desktop、OpenClaw、Hermes 和 Pi 首页 Tab 显隐设置被后端过滤的问题。
- 至少保留一个可见 Tab，支持拖拽与键盘排序，隐藏活动 Tab 时自动回退。
- 修复防抖保存、返回首页和并发读取之间的同步竞态。
- 优化设置页焦点、拖拽反馈、减少动画与中窄窗口布局。
- 应用版本推进至 `v2.10.2`，同步全平台构建元数据及 `RELEASE_NOTES.md`。

## 验证记录

- 发布前功能修复已通过 482 项前端单元测试、TypeScript 类型检查、Go 服务测试和差异检查。
- 按用户要求，发布阶段不再重复运行测试。
