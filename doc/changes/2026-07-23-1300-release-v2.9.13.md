# 发布 v2.9.13

- 变更时间：2026-07-23 13:00:08 CST（Asia/Shanghai）
- 涉及范围：应用版本、供应商日志红点、供应商配置持久化、Wails 构建元数据、发布说明、Git Tag、GitHub 自动打包

## 变更内容

- 应用版本从 `v2.9.12` 更新为 `v2.9.13`。
- Claude、Codex 和 Gemini 的供应商日志弹窗新增独立红点开关，默认开启。
- 关闭红点后继续保留日志采集及未读记录，日志图标仅打开弹窗。
- 开关修改即时保存，保存失败时自动恢复原状态。
- 新增向后兼容的 `hideLogBadge` 配置字段，并打通三类供应商的读取与保存映射。
- 同步 macOS、Windows、Linux 平台构建元数据。
- 创建并推送 `v2.9.13` Tag，触发 GitHub Actions 全平台自动打包。
